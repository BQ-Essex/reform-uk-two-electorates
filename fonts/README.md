# Fonts

Lora and Lato, used by `build_report.py` to embed the report's typography as base64
web fonts (so `report.html` and the print PDFs render correctly without the reader
needing either font installed).

Both are Google Fonts, released under the **SIL Open Font License 1.1**, which
permits bundling and embedding in software and documents. See
<https://scripts.sil.org/OFL> for the licence text.

| File | Family | Source |
|------|--------|--------|
| `Lora-Variable.ttf`, `Lora-Italic-Variable.ttf` | Lora (display serif) | <https://fonts.google.com/specimen/Lora> |
| `Lato-Regular.ttf`, `Lato-Italic.ttf`, `Lato-Bold.ttf`, `Lato-Light.ttf` | Lato (body) | <https://fonts.google.com/specimen/Lato> |
